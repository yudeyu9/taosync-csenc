# 后端 / 镜像构建备忘

> 本文件为开发备忘。公开部署请优先看仓库根目录 README 与 `deploy/synology/`。

## 群晖 / 本机构建（推荐）

先构建前端，再在仓库根目录构建镜像：

```sh
npm run build --prefix web
docker build -t taosync-csenc:local .
```

运行：

```sh
docker run -d -p 8023:8023 -v /path/to/data:/app/data --name=taoSync taosync-csenc:local
```

## 仅用 PyInstaller（可选）

在 Linux 构建环境中安装依赖后：

```sh
pip install --no-cache-dir -r requirements.txt pyinstaller
pyinstaller taoSync.spec
```

产物在 `dist/taoSync`。
